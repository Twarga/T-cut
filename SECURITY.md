# Security policy

## Current support

This repository contains planning documents, brand assets and a static website. No T-cut editor release is available. The maintained website source is on `main`; there are no supported editor binaries or published security guarantees.

## Report privately

Use GitHub’s [private vulnerability reporting](https://github.com/Twarga/T-cut/security/advisories/new) for a sensitive finding. Include:

- Affected file, URL or revision.
- Reproduction steps and expected versus observed behavior.
- Impact and any required permissions.
- A minimal demonstration without private media, credentials or destructive actions.

Do not post credentials, exploitable private information or somebody else’s media in a public issue. If GitHub’s private report form is unavailable, open a public issue requesting a private contact **without vulnerability details**.

No fixed response-time or bounty commitment is currently offered. A maintainer must review proposed security fixes before public release.

Future media parsers, project formats, templates, model workers and optional services need the threat-model and release evidence described in the [quality plan](docs/plan/quality-release.md).
